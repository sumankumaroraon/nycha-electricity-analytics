Monthly consumption and effective cost

Bars show consumption; the line shows what each kWh cost once all bill charges are included. The selected year is shaded darker.

Effective cost = total reported charges ÷ total kWh. It includes demand and other charges, so it is not a tariff rate. Months with fewer bills than usual understate consumption.

What changed spending

Each development-month is compared with the same month a year earlier. Changes where either month has no consumption are shown separately, so the bridge always adds up.

This is an accounting split, not proof that a tariff changed. Consumption effect = change in kWh × last year's cost per kWh. Effective-cost effect = this year's kWh × change in cost per kWh.
